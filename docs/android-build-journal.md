# Android build journal

Use this short template for each future candidate. Keep detailed current state
in [android-status.md](android-status.md), and keep raw captures in ignored
`out/` directories. A successful compile is not a runtime fix.

Record the scene, duration, cache state, GPU clock and approximate temperature
for performance comparisons. Ask before beginning a new build or phone test.
